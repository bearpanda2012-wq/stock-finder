# ค้นหาหุ้นอัจฉริยะ

สกรีนเนอร์หุ้นไทย (SET/mai) หุ้นสหรัฐฯ และคริปโต — ไฟล์ HTML เดียวจบ ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้อง build

## โครงสร้างโฟลเดอร์

```
stock-finder/
├── index.html              ← เว็บแอป (ไฟล์เดียวจบ) — นี่คือไฟล์ที่ GitHub Pages เสิร์ฟ
├── manifest.webmanifest    ← ข้อมูลแอปสำหรับติดตั้ง (ชื่อ ไอคอน สี)
├── sw.js                   ← Service Worker: เปิดได้ตอนออฟไลน์ + แจ้งเวอร์ชันใหม่
├── icons/                  ← ไอคอนแอป 192/512/maskable/apple-touch/favicon
├── README.md
├── .gitignore
├── supabase/
│   └── schema.sql          ← ตารางฐานข้อมูลสำหรับระบบสมาชิก (ไม่ใช้ก็ได้)
├── proxy/                  ← ใช้เฉพาะตอนติด CORS
│   ├── worker.js           Cloudflare Worker ทำหน้าที่ proxy
│   └── wrangler.toml       ตั้งค่าสำหรับ deploy ด้วย CLI
└── cowork/
    └── stock-finder.html   เวอร์ชันเดิมที่รันเป็น artifact ใน Claude Cowork (ใช้ MCP + AI)
```

`index.html` กับ `cowork/stock-finder.html` เป็นคนละเวอร์ชันกัน อ่านหัวข้อ "สองเวอร์ชันต่างกันยังไง" ด้านล่าง

## ความสามารถ

- **สลับตลาด** หุ้นไทย / หุ้นสหรัฐฯ / คริปโต
- **ค้นหาด้วยชื่อ** — `PTT`, `ปตท`, `AAPL NVDA TSLA`, `bitcoin` (ใส่หลายตัวคั่นเว้นวรรคได้ · สลับตลาดให้อัตโนมัติเมื่อเจอในตลาดอื่น)
- **ค้นหาด้วยเงื่อนไขภาษาไทย** — `ปันผลเกิน 5% และ P/E ต่ำกว่า 12`, `รายได้โต 15% ROE เกิน 20`, `RSI ต่ำกว่า 35`
- **กลยุทธ์สำเร็จรูป** 7 แบบสำหรับหุ้น + 4 แบบสำหรับคริปโต
- **ตัวกรองละเอียด** 14 ตัวแปร กรอกช่วงต่ำสุด–สูงสุด
- **คะแนน 0–100** จาก 5 องค์ประกอบ (คุณค่า / คุณภาพ / เติบโต / โมเมนตัม / เทคนิค) ปรับน้ำหนักเองได้ จำค่าไว้ข้ามครั้ง
- **แผงรายตัว** — กราฟเรดาร์, สัญญาณเทคนิค 5 กรอบเวลา, ข่าว/เหตุการณ์, ราคาเป้าหมายนักวิเคราะห์, ข้อมูลบริษัท, ที่มาของคะแนน

## AI สแกนประจำวัน

ทุกเช้า **08:30 น.** (เวลาไทย) เซิร์ฟเวอร์จะสแกนหุ้นให้เอง ไม่ต้องเปิดแอปค้างไว้ เปิดแอปมาก็เห็นการ์ด "AI สแกนประจำวัน" บนสุด

- สแกนหุ้นใหญ่ 300 ตัวต่อตลาด (คริปโตราว 120 เหรียญ) ให้คะแนน 5 ด้านด้วยสูตรเดียวกับหน้าเว็บ
- คัดเป็นกลุ่ม: คะแนนสูงสุด · ถูกและดี · โมเมนตัมแรง · ขายมากเกินไปลุ้นเด้ง · สัญญาณกลับตัว · วอลุ่มผิดปกติ
- ให้ **Gemini** เขียนบทสรุปภาษาไทย + เลือกหุ้นน่าจับตา 3–5 ตัวพร้อมเหตุผล (ใช้เฉพาะตัวเลขที่ส่งให้ ห้ามแต่งข่าว)
- เก็บย้อนหลัง 7 วันให้กดดูได้ · เสาร์-อาทิตย์สแกนเฉพาะคริปโต
- หุ้นไทยทุกคนดูได้ · สหรัฐฯ/คริปโต เฉพาะ Pro/Lifetime (บังคับด้วย RLS ที่ฐานข้อมูล)
- แอดมินมีปุ่ม **⟳ สแกนตอนนี้** สั่งสแกนใหม่ได้ทันที

**เปิดใช้ Gemini (ฟรี)** — ตอนนี้ระบบทำงานแล้วแต่ใช้ "สรุปอัตโนมัติจากกฎ" จนกว่าจะใส่ key

1. สร้าง key ที่ https://aistudio.google.com/apikey
2. Supabase Dashboard → **Edge Functions → Secrets** → Add new secret
   ชื่อ `GEMINI_API_KEY` ใส่ key ที่ได้ → Save
3. รอรอบเช้าถัดไป หรือให้แอดมินกด "⟳ สแกนตอนนี้" ในแอป — ป้ายบนการ์ดจะเปลี่ยนจาก "อัตโนมัติ" เป็น "Gemini"

ชื่อ secret จะเป็นอะไรก็ได้ที่มีคำว่า `gemini` · ไม่ใส่ `GEMINI_MODEL` ก็ได้ ระบบจะไล่ลองหลายรุ่นเองถ้ารุ่นแรกไม่ว่าง

ส่วนประกอบ: ตาราง `daily_scans` · Edge Function `supabase/functions/daily-scan` ·
งานตั้งเวลา pg_cron `daily-ai-scan` · รหัสลับใน Vault `daily_scan_cron_secret` (รายละเอียดใน `supabase/schema.sql` ส่วนที่ 6)

### AI คัดแล้ว · จุดเข้าซื้อตามระบบ

อยู่ในการ์ด AI สแกนประจำวัน ใต้ "หุ้นน่าจับตา" — Edge Function `trade-signals` ทำงานต่อจาก daily-scan ทุกเช้า 08:40 น.

- คัดจากหุ้นที่ daily-scan เลือกไว้ แล้วใช้ **กติกาตายตัว 3 แบบ**: ย่อในขาขึ้น · ทะลุจุดสูงสุด 52 สัปดาห์ · เด้งจากขายมากเกิน
- แต่ละสัญญาณบอก **โซนราคาเข้า · จุดตัดขาดทุน · เป้า 1/2 · ใช้ได้ถึงวันที่** (ระยะทั้งหมดคำนวณจาก ATR) วันละไม่เกิน 5 ตัวต่อตลาด
- ระบบ **ติดตามผลจริงเอง** ทุกวัน: รอเข้า → เข้าแล้ว → ถึงเป้า / ตัดขาดทุน / หมดอายุ แล้วโชว์สถิติชนะ/แพ้ 90 วันให้สมาชิกเห็น
- นับผลแบบมองแง่ร้าย: วันเดียวแตะทั้งตัดขาดทุนและเป้า = ขาดทุน
- ไม่ได้บอกเวลาซื้อขายรายนาที และไม่มีระบบใดทายราคาได้แม่นยำ — ป้ายในแอปเขียนไว้ชัดว่าไม่ใช่คำแนะนำการลงทุน
- ถ้าจะเก็บเงินสมาชิกโดยมีฟีเจอร์นี้ ควรปรึกษาผู้เชี่ยวชาญเรื่องใบอนุญาตของ ก.ล.ต. ก่อน

ปรับกติกาได้ที่ `supabase/functions/trade-signals/index.ts` · ข้อมูลอยู่ในตาราง `trade_signals`

### AI วิเคราะห์รายตัว + แผนเทรดในตาราง

- ตารางหลักมีคอลัมน์ **"แผน AI · โซนเข้า"** — คำนวณในเบราว์เซอร์ด้วยกติกาเดียวกับ trade-signals (ไม่ใช้ AI ไม่เปลืองโควตา)
- กดหุ้นเปิดแผงรายละเอียด → หัวข้อแรก **AI วิเคราะห์**: รูปแบบ · โซนเข้า · ตัดขาดทุน · เป้า 1/2 · ใช้ได้ถึง · สถานะ
  แล้วตามด้วยบทวิเคราะห์ Gemini (ภาพรวม / จุดแข็ง / ความเสี่ยง / มุมมองต่อแผน)
- Edge Function `ai-analyze`: ต้องล็อกอิน · หุ้นสหรัฐฯ/คริปโตเฉพาะ Pro · แคชในตาราง `ai_notes` วันละครั้งต่อหุ้น
  (คนถัดไปเปิดหุ้นเดียวกันได้ทันที) · สร้างใหม่ได้ 30 ครั้ง/คน/วัน
- ใช้รุ่น Lite ก่อนเพื่อความเร็ว (~10 วิ) ถ้า Gemini ไม่ว่างจะตอบกลับภายใน ~80 วิ พร้อมปุ่ม "ลองใหม่"
- ตัวเลขโซนราคาคำนวณจาก **แท่งรายวันที่ปิดแล้ว** (ระหว่างตลาดเปิดใช้แท่งเมื่อวาน · คริปโตตัดรอบ 07:00 น.) ตารางกับบทวิเคราะห์ AI จึงตรงกันเสมอ

## ติดตั้งเป็นแอป (PWA)

เปิดจาก GitHub Pages (ต้องเป็น https) แล้วติดตั้งได้เลย ไม่ต้องลงสโตร์

| อุปกรณ์ | วิธีติดตั้ง |
|---|---|
| Android (Chrome) | กดปุ่ม **⤓ ติดตั้งแอป** บนหัวเว็บ หรือเมนู ⋮ → ติดตั้งแอป |
| คอม (Chrome / Edge) | ปุ่ม **⤓ ติดตั้งแอป** หรือไอคอนติดตั้งท้ายแถบที่อยู่ |
| iPhone / iPad | ต้องใช้ **Safari** → ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม (กดปุ่มติดตั้งแอปในเว็บจะขึ้นวิธีให้) |

ความสามารถเมื่อเป็นแอป

- เปิดเต็มจอ มีไอคอนบนหน้าจอโฮม แถบสถานะเปลี่ยนสีตามโหมดสว่าง/มืด
- **เน็ตหลุดก็เปิดได้** — แสดงผลคัดกรองชุดล่าสุดของแต่ละตลาดที่เคยโหลดไว้ พร้อมบอกเวลาที่บันทึก
- **อัปเดตอัตโนมัติ** — อัปโหลด `index.html` ใหม่ขึ้น GitHub ผู้ใช้จะได้เวอร์ชันใหม่ในการเปิดครั้งถัดไป
- ข้อมูลราคา, Supabase (ล็อกอิน/ข้อมูลส่วนตัว) และการแปลภาษา **ไม่ถูกแคช** — ดึงสดทุกครั้ง

**ถ้าแก้ `sw.js`, ไอคอน หรือเปลี่ยนเวอร์ชันไลบรารี CDN** ให้เปลี่ยน `VERSION` บนสุดของ `sw.js`
(เช่น `sf-v1` → `sf-v2`) ผู้ใช้จะเห็นแถบ “มีเวอร์ชันใหม่ของแอป · อัปเดต”
แก้แค่ `index.html` ไม่ต้องเปลี่ยน เพราะหน้าเว็บดึงจากเน็ตก่อนเสมอ

เปิดจากไฟล์ในเครื่อง (`file://`) จะใช้งานได้ตามปกติ แต่ติดตั้งเป็นแอปไม่ได้ — เบราว์เซอร์อนุญาตเฉพาะ https หรือ localhost

## ถ้าตารางว่างเปล่า / ขึ้นว่าถูกบล็อกโดย CORS

`index.html` เรียก TradingView public scanner ตรงจากเบราว์เซอร์ ถ้า TradingView ไม่ยอมให้เรียกข้ามโดเมน ให้วาง proxy คั่นกลาง:

**วิธีที่ 1 — ผ่านหน้าเว็บ Cloudflare (ง่ายสุด)**

1. ไป dash.cloudflare.com → Workers & Pages → Create → Worker
2. วางเนื้อหาไฟล์ `proxy/worker.js` ทับโค้ดตัวอย่าง
3. แก้ค่า `ALLOW` ในไฟล์ให้เป็นโดเมน GitHub Pages ของคุณ แล้วกด Deploy
4. คัดลอก URL ที่ได้ เช่น `https://tv-proxy.yourname.workers.dev`

**วิธีที่ 2 — ผ่าน CLI**

```bash
cd proxy
npx wrangler deploy
```

จากนั้นแก้ใน `index.html` บรรทัดเดียว:

```js
const TV = "https://scanner.tradingview.com";
// เปลี่ยนเป็น
const TV = "https://tv-proxy.yourname.workers.dev";
```

### อัปเกรดสมาชิก

ผู้ใช้แก้ `tier` ตัวเองไม่ได้ (RLS ปิดไว้) ต้องสั่งจากฝั่งเซิร์ฟเวอร์ — Dashboard → SQL Editor:

```sql
update public.profiles set tier='pro' where email='you@example.com';
```

รับเงินจริง: สร้าง Stripe Payment Link → ใส่ URL ในช่อง `upgradeUrl` → ทำ webhook (Supabase Edge Function)
รับ event `checkout.session.completed` แล้ว `update profiles set tier='pro', tier_expires_at=now()+interval '1 month'`

**สำคัญ:** การจำกัดสิทธิ์ในหน้าเว็บเป็นเรื่อง UX เท่านั้น คนที่แก้โค้ดในเบราว์เซอร์ยังดูข้อมูลได้
เพราะข้อมูลหุ้นมาจาก TradingView ที่เปิดสาธารณะอยู่แล้ว ส่วนข้อมูลส่วนตัวปลอดภัยจริงเพราะ RLS บังคับที่ฐานข้อมูล
